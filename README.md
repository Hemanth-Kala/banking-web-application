# Banking Web Application

A professional-style banking web application built using Python, Flask, HTML, CSS, and Oracle Database.

## Features
- Customer Registration and Login
- Bank Admin Login
- Account Management
- Deposit and Withdrawal
- Money Transfer
- Balance Enquiry
- Transaction History

## Technologies Used
- Python
- Flask
- HTML
- CSS
- Oracle Database
